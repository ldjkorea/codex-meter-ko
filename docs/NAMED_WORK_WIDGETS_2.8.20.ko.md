# GPT HUD 2.8.20 beta — 작업 이름과 위젯 수정

2026-10-10. Android 2.8.20 / versionCode 50 / dev.bennett.codexmeter. Windows Widget 0.1.6 beta.

## 실제 변경

- PC 수집기는 Codex의 로컬 제목 DB를 읽기 전용으로 열고 사용자 지정 이름 또는 작업 제목만 전달합니다. DB가 없거나 잠겨 있으면 기존 짧은 식별자 표시로 돌아갑니다. 제목은 길이 제한·제어 문자 정리·일반적인 토큰 형태 가리기를 적용합니다. 대화 원문, 명령 내용, 도구 결과, 인증 정보를 전달하지 않습니다. Codex 설정·Hooks를 설치하거나 Codex를 재시작하지 않았습니다.
- 작업 중, 턴 완료·다음 요청 대기, 중단을 작업 이름과 함께 표시합니다. 구조화된 실행 결과의 명령·도구 오류는 별도 경고이며 작업 전체의 실패로 바꾸지 않습니다. 오래된 다른 턴의 오류가 현재 턴을 덮어쓰지 않습니다. 이후 정상 도구 결과가 관측되면 경고를 해제합니다.
- 재시작 시 최근 24개 로그 중 최신 3개의 끝 8MiB, 나머지의 끝 1MiB에서 2시간 이내의 실제 시작·종료 이벤트만 복구합니다. 이후 기존 증분 감지를 사용합니다. 범위 밖의 시작 이벤트를 찾지 못하면 상태를 추측하지 않고 새 턴을 기다립니다.
- 작업 현황 위젯에 확인된 티어의 기존 삼족오·색상·장식을 적용했습니다. 미확정 티어는 기록 수집 상태입니다. 가로·세로 크기에 맞춰 1~3개 작업과 최근 연결 시각을 표시하고 별도 새로고침 버튼을 제공합니다. 오프라인에서는 마지막 확인값임을 표시합니다. 기존 위젯 ID와 연결 설정을 보존합니다.
- 진화형 위젯 설정 미리보기의 AppCompat RemoteViews 생성 오류를 수정했습니다. 작은 크기에서 모든 항목이 사라지던 처리를 간결한 배치로 바꾸고, 공간이 부족할 때는 확대 안내와 들어가는 항목을 보여줍니다. 확대한 뒤 원래 선택 항목을 복원하며 저장된 선택·색상·투명도를 초기화하지 않습니다.
- 앱의 새로운 기능·전체 릴리스 기록에 이번 변경을 추가했습니다. OAuth·UsageApi·SQLite 원장·티어 및 가성비 계산·기존 위젯의 옵션과 서명을 유지했습니다.

## 현재 PC 확인

- 실제 Codex 제목 DB 및 최근 이벤트에서 이름이 있는 작업 3개와 작업 중 상태 3개를 읽었습니다. 공개 보고서에 실제 작업 제목·기기·스레드 식별자를 넣지 않았습니다.
- 이 PC의 바탕화면 실행 파일을 0.1.6으로 업데이트했고 정상 실행 중입니다. 기존 실행 파일은 별도로 보관했습니다. 로그인·페어링 보호 파일의 해시가 교체 전후 동일했습니다. Codex 프로세스와 설정은 건드리지 않았습니다.
- 실행 중인 PC 위젯의 기존 인증된 로컬 TLS 상태 서비스에서 실제 이름 3개, 작업 중 3개, 최근 heartbeat를 확인했습니다. 휴대폰 또는 Tailscale 외부망 전달까지 확인한 결과는 아닙니다.

## 한계와 필요한 휴대폰 확인

1. 승인 대기·입력 대기·치명적인 턴 실패를 구분하는 이벤트는 현재 수집기에 연결하지 않았습니다. 턴 완료 후의 다음 요청 대기와 명령·도구 오류만 근거 있게 표시합니다. 명령 실패를 프로젝트 전체 실패로 판단하지 않습니다.
2. 상세 화면은 기존 15초 확인입니다. 백그라운드 상태 위젯은 Android JobScheduler의 약 15분 최선 노력 갱신이며 Doze에서 지연됩니다. 15초 백그라운드 실시간 갱신을 보장하지 않습니다.
3. 실제 삼성 갤럭시에서 새 APK 설치·작업명 수신·위젯 확대 핸들·Tailscale LTE/5G·절전·재부팅은 미검증입니다. 사용자의 이전 버전 외부망 성공 보고를 이번 버전 실기기 성공으로 확대하지 않습니다.
4. 원래 11종 사용량 위젯, AOD·Now Bar·Wear의 빌드·회귀 검사는 통과했지만 실제 각 표면을 새 버전 기기에서 실행하지는 않았습니다.
