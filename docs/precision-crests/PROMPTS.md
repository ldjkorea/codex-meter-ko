# Precision Crests artwork provenance

Built-in image generation mode; ten separately generated original transparent assets. Approved `codex-precision-crests-v1.png` was used as a visual reference. The app uses the optimized WebP files named in ASSETS.json, not the presentation board. No external logos or historical insignia were imported.

## Common prompt

One isolated production-ready original prestige achievement emblem for Codex Meter. Single centered frontal symmetric emblem, fully visible, transparent background including gaps; no label, title or scenery. Premium AAA achievement art with believable machined 3D metal, precise stepped architectural plates, deep bevels and selective highlights. Central faceted computational crystal with subtle angle brackets. No faces, robots, animals, feathers, crowns, royal/historical insignia, laurel or company logos. Match the approved futuristic precision concept and preserve aspirational tier hierarchy. Restrained studio light; no excessive bloom or particles.

## Tier directions

| Tier | Prompt direction |
|---|---|
| Iron | Compact graphite/gunmetal nested frame, smoky-gray crystal; reserved early-tier architecture. |
| Bronze | Copper/bronze over graphite, amber-brown crystal, three compact side layers. |
| Silver | Polished silver, clear white crystal, modest raised side plates and top keystone. |
| Gold | Champagne gold over black titanium, amber-white core, developed but moderate side arrays. |
| Platinum | White platinum, teal core, raised three-tier arrays and detached upper bars. |
| Emerald | Dark graphite/platinum, rich emerald core and green insets, more developed side layers. |
| Diamond | Match the concept's middle platinum/ice-blue emblem, expansive precise arrays and crystal supports. |
| Master | Expanded five-layer graphite/rose-platinum arrays, violet insets, amethyst core, stepped floating elements. |
| Grandmaster | Wide graphite/rose-gold arrays, ruby core, two detached upper bars each side and deeper layered architecture. |
| Challenger | Match the concept's right emblem: broad luxurious champagne-gold/obsidian arrays, ice-white/cyan core, crystal keystones and greatest material depth. |

Packaging only resizes/compresses the generated art into transparent 512px WebP using the maintainer's existing Sharp runtime. No Sharp dependency is added to Android or CI. Source images remain in local delivery storage; approved production hashes are public and reproducible for packaging verification. Existing project MIT license applies to these original distributed assets.
