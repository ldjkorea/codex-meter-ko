# Codex Meter 2.8.3 / 33 — UI v3

- 메인은 내 사용량 한눈에, 작은 구독 가성비 카드, 한도 상세보기로 간결해졌습니다. 기본 주간 한도 구간은 한 번만 표시합니다.
- 새로고침은 현재 화면에서 조회·저장·갱신하며 반복 터치로 요청이 중복되지 않습니다.
- 사용량 분석 진입을 요약 / 추세 / 기록 / 가성비로 통합하고 기존 고급 차트는 하위 진입으로 유지합니다.
- 이번/이전 서버 한도 구간과 최근 7/30일을 구분하며 동일 경과 시간의 관측 범위가 충분할 때만 이전 구간과 비교합니다.
- 차트 선택을 강조하고 선택 날짜의 사용량·측정 상태를 아래에 표시합니다. 달력 중심으로 날짜를 선택하고 중복 목록을 제거했습니다.
- 실제 결제액·통화·기간을 계정/플랜별로 입력합니다. 출처가 없는 API 환산 가정은 화면에서 사용하지 않고 확정 절약액으로 표시하지 않습니다.
- 5시간 OFF를 홈·삼성 잠금화면/AOD 위젯·미리보기·Now Bar·새 Wear 표시 경로에 반영합니다. 데이터와 기존 디자인/선택은 유지하며 OFF 때 빈 5시간 슬롯을 만들지 않습니다.
- Reset Credit 직접 실행 버튼·알림 액션을 제거하고 횟수·만료 정보·변동 기록을 유지합니다.
- OAuth·API·원장 DB·기존 집계·예측·SAF 내보내기 및 사용자 데이터는 유지합니다. 키·패키지를 유지하고 버전은 2.8.3/33입니다.
