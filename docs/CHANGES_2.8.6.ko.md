# Codex Meter 2.8.6 변경사항

- Matte Black 디자인과 분석/홈/기록 탭, 홈의 사용량 → 티어 → 코치 → 가성비 순서를 유지합니다.
- 코치 말투마다 문장을 다르게 만들었습니다. 기록 부족도 짧게 반응하고, 소진 임박·초기화 직후·높고 낮은 활용도·조건이 충족된 비교와 개인 최고 기록을 다룹니다. 당일 같은 상태의 새로고침으로 문장이 무작위 변경되지 않습니다.
- 구독 가성비는 입력한 세금 포함 결제액을 이번 한도 기간에 배분한 금액입니다. 임의 100,000원 환산이나 몇 배 이득은 현재 화면에서 사용하지 않습니다.
- 기록 탭의 여섯 설정 아코디언을 없애고 표시 스위치 세 개(5시간/주간/한눈에)와 설정 버튼만 남겼습니다.
- 계정·구독, 가성비·코치, 알림·갱신, 위젯·화면, 데이터, 앱 정보를 별도 설정에서 관리합니다. 기존 설정 진입도 같은 화면으로 연결됩니다.
- 날짜에 배분하지 않은 변화량·내보내기·고급 원장·삭제는 설정의 데이터 관리로 이동했습니다. 달력·날짜 상세·이벤트는 기록에 남습니다.
- 테스트 메모 메뉴·버튼·테스트 모드 전환을 숨겼습니다. 저장된 메모는 삭제하지 않습니다.
- 로그인·SQLite·사용량 API·결제 이력·티어·결산·위젯·Wear·5시간 숨김 정책·초기화 크레딧 정보는 보존합니다.

실제 삼성 기기 설치·화면 렌더링은 아직 검증하지 못했습니다.
