## 실제 변경

- 홈: 기존 고화질 삼족오 중앙 배치 → 실제 영어 대문자 티어명 → 이번 주간 사용량 → 기능 ON일 때 작업 현황 행 → 기존 AI의 한마디와 가성비. 기록 부족 시 임의 티어를 만들지 않습니다.
- 주간 카드: 서버 구간, 사용률·잔여율, 초기화 남은 시간과 실제 시각, 오늘 관측 증가량(%p), 최신성, 한도 상세보기·새로고침을 유지했습니다. 실제 제공되는 월간·다른 한도로 대체하고 Plus 5시간 초기화 안내도 유지합니다.
- 정밀도: 원본 double 값과 기존 int 호환 필드를 분리했습니다. 표시만 공통 HALF_UP 규칙으로 최대 세 자리 반올림합니다. 13은 13%, 13.42736은 13.427%, 잔여율은 원본에서 계산합니다. 기존 정수 캐시와 동기화 형식을 유지하고, 맞지 않는 정밀 필드는 무시합니다.
- 기록: 분석·기간 선택 → 캘린더 → 선택 날짜 요약 → 설정. 좁은 화면의 기간 버튼은 2×2입니다. 월 화살표와 가운데 연월의 현재 월 복귀를 연결했습니다.
- 설정: 계정 및 구독 / 화면 및 위젯 / 알림 및 새로고침 / PC 연결 및 작업 현황 / 기록 및 데이터 / 앱 정보. 관측 기록·변화 이벤트·표시 옵션·CSV/JSON을 이곳에 모았습니다. 삭제·로그아웃 확인은 유지합니다.
- 작업 현황: 기존 페어링·Tailscale·메타데이터 수집기를 재사용합니다. 연결 상태와 마지막 확인값을 구분하고 역순 스냅샷을 차단합니다. 별도 기존 시험 공급자를 GPT HUD · Codex 작업 현황 이름으로 제공합니다. 기존 사용량 위젯 공급자·설정을 변경하지 않았습니다.
- 상세 화면이 열린 동안 15초 확인합니다. 상태 위젯이 설치되어 있고 기능 ON인 경우에만 Android JobScheduler의 15분 최선 노력 갱신을 등록합니다. 기능 OFF 시 신규 요청·예약을 중단합니다. Doze에서는 늦어질 수 있습니다.
- 자체 제품명은 GPT HUD로 정리했습니다. 원작의 저작권·MIT 고지와 과거 릴리스는 보존했습니다. 새로운 기능 및 전체 릴리스 기록에 이번 변경을 추가했습니다.

## 실제 데이터·연결 확인

- PC의 현재 계정에 연결된 최근 정상 관측 캐시를 읽었으며, 주간 한도 값은 정수였습니다. 토큰·계정 식별자·원문 응답을 출력하거나 저장하지 않았습니다.
- 별도의 읽기 전용 실시간 usage GET 확인은 성공하지 못했습니다. 인증 갱신·캐시 변경 없이 종료했습니다. 따라서 이번 작업에서 새 서버 응답의 실제 소수 정밀도를 확인했다고 주장하지 않습니다. 소수·정수 응답 처리와 반올림은 합성 원본 응답 테스트로 확인했습니다.
- 현재 실행 중인 PC의 실제 Codex 수집기에서 최근 heartbeat와 현재 작업의 running, 다른 작업의 completed를 읽기 전용으로 확인했습니다. 공개 자료에 기기/스레드 식별자나 작업 원문을 포함하지 않았습니다.
- 사용자가 2.8.18에서 휴대폰 Wi-Fi OFF / LTE·5G / Tailscale ON 상태의 연결 시각 갱신을 확인했습니다. 이 사용자 보고는 기존 경로의 증거입니다. 2.8.19 실제 휴대폰의 화면·새 위젯·백그라운드 성공 증거로 확대하지 않습니다.
- 기존 수집기는 작업 중·턴 완료·중단을 지원합니다. 승인 대기·입력 대기·실패를 별도의 실측 이벤트 없이 만들지 않습니다. 공식 Hooks는 신뢰 검토가 필요한 별도 통합이므로 기존 Codex를 재시작하거나 설정에 자동 설치하지 않았습니다. 참고: https://developers.openai.com/plugins/build/plugins
