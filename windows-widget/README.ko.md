# Codex Meter Windows Widget 0.1.0 beta

Windows 바탕화면에서 원하는 위치로 옮기고 크기를 조절하는 작은 사용량 위젯입니다. Windows의 Win+W 패널에 등록하는 방식은 아닙니다. OpenAI가 제공하는 공식 제품이 아니며 Windows 10/11과 .NET Framework 4.8 환경을 대상으로 합니다.

## 실행

1. `CodexMeter-WindowsWidget-0.1.0-beta.zip`을 내려받고 **모두 압축 풀기**를 누릅니다.
2. 압축을 푼 폴더의 `CodexMeterWidget.exe`를 실행합니다. ZIP 안에서 바로 실행하지 마세요.
3. **로그인**을 누르고 열린 브라우저에서 직접 ChatGPT 계정에 로그인합니다.
4. 위젯 상단을 끌면 이동하고 가장자리를 끌면 크기를 조절합니다.
5. **⋯** 또는 오른쪽 클릭 메뉴에서 **항상 위에 표시**, 투명도, 글자 크기, 5시간 한도 표시를 바꿉니다.
6. 필요한 경우에만 **Windows 시작 시 실행**을 켭니다. 실행 파일을 옮기면 이 설정을 껐다 다시 켜 주세요.

F5는 새로고침, Shift+F10은 메뉴입니다. 닫으면 작업 표시줄의 숨겨진 아이콘 영역으로 들어갑니다. 아이콘을 두 번 누르면 다시 보이고 메뉴의 **종료**로 완전히 닫습니다.

Windows 코드 서명 인증서가 없어 실행 파일의 게시자는 검증되지 않습니다. SmartScreen 경고가 나타날 수 있습니다. 공개 릴리스의 파일과 체크섬을 확인하고 신뢰할 수 있는 경우에만 실행하세요. 시스템 보안 기능 전체를 끄거나 관리자 권한으로 실행할 필요는 없습니다.

## 표시와 기록

- 서버가 제공한 주간 한도를 우선하고 월간·5시간 한도가 있으면 해당 한도로 대체합니다. 5시간 표시를 끄면 해당 수치도 숨깁니다.
- 로그인 후 5분 간격으로 조회합니다. 수동 새로고침은 30초 간격을 두며 동시에 여러 요청을 실행하지 않습니다.
- 15분 이상 오래된 값, 조회 실패, 초기화 경과 시 마지막 관측값이라는 표시를 붙입니다. 초기화가 지났다고 임의로 잔여량을 100%로 만들지 않습니다.
- 오늘 관측값은 서울 날짜 기준의 같은 초기화 구간 안에서 확인된 증가분(%p)입니다. 자정 경계·6시간 초과 관측 공백·사용률 감소·정책 변경의 차이는 계산하지 않습니다. 실제 하루 전체 사용량으로 단정하지 않습니다.
- PC 기록과 휴대폰 기록은 자동 공유되지 않습니다. PC 티어는 PC에서 모인 충분한 완료 주간 관측만으로 계산합니다. 초기에는 흐린 Iron 이미지와 **티어 기록 수집 중**을 표시하며, 초기 등급은 **잠정**으로 구분합니다. 현재 사용률 하나로 휴대폰 티어를 복제하거나 등급을 만들지 않습니다.
- 추가 한도·크레딧·구독료·캘린더·Wear 화면은 이번 PC 위젯에 포함하지 않습니다. 휴대폰 기능은 그대로 유지합니다.

## 저장과 개인정보

저장 위치는 `%LOCALAPPDATA%\CodexMeterWidget`입니다. 토큰은 현재 Windows 사용자에게 묶인 DPAPI 암호화 파일로 저장합니다. PC Codex의 인증 파일·세션·대화 원문을 읽지 않습니다.

계정 식별자의 SHA-256으로 구분한 폴더에 관측 사용량·플랜·한도 길이·초기화 시각을 기록합니다. 기록 파일에 인증 토큰·이메일·대화 내용은 넣지 않습니다. 파일은 임시 파일을 완전히 쓴 뒤 교체하고 마지막 사본을 보관합니다. 조회/쓰기 실패 시 마지막 정상 관측을 유지합니다. 로그아웃은 암호화된 로그인 정보만 지우고 계정별 사용 기록을 보존합니다.

일별 JSON 원시 관측을 보존하고 계산에는 최근 90일을 읽습니다. 기록을 자동 삭제하지 않습니다. 폴더를 외부에 공유할 때는 `credentials.dpapi`, `.bak`, 개인 기록을 포함하지 마세요. 원본 계정의 한도를 보여주는 도구이며 토큰 비용·결제 토큰·생산성 측정기는 아닙니다.

## 검증 범위

78개 로컬 자동 검사와 18개 화면 비트맵 생성 검사를 통과했습니다. 암호화 저장·재읽기·계정 분리·동시 기록·중복·자정/초기화/정책 변경·가상 API·PKCE/상태 검사를 포함합니다. 실제 계정의 로그인, 실서버 조회, 장시간 자동 실행, 다중 모니터 이동, 실제 바탕화면 클릭/트레이/DPI 환경은 아직 검증하지 않았습니다. 화면 예시는 가상 데이터로 그린 것이며 실계정 화면이 아닙니다.

문제가 생기면 기록 폴더를 지우지 말고 오류 상황을 알려 주세요. 로그인 실패 시 진행 중인 다른 Codex 로그인을 마친 뒤 메뉴에서 다시 시도할 수 있습니다. 동시 로그인 포트 충돌이나 서버의 OAuth 정책에 따라 실제 계정 검증이 추가로 필요할 수 있습니다.

## 개발

소스와 10개 휘장을 포함하며 프로젝트 MIT 라이선스를 유지합니다. Windows 시스템 글꼴을 사용하고 외부 런타임/SDK를 새로 설치하지 않습니다. 기존 .NET Framework 컴파일러로 `./windows-widget/build.ps1 -Test`를 실행하면 EXE와 별도의 가상 데이터 검증 파일을 만듭니다. 테스트는 실서비스 로그인과 자동 실행 레지스트리 변경을 수행하지 않습니다.
